# 📚 Estudos de PLN e Análise de Dados

Bem-vindo ao meu repositório de estudos! 🚀

Este espaço foi criado com o objetivo de documentar meu aprendizado e aprofundar meus conhecimentos na área de **Processamento de Linguagem Natural (PLN)** e **Ciência de Dados** durante a faculdade.

## 🎯 Objetivo
Meu foco aqui é transformar a teoria da graduação em prática, explorando como tratar dados reais, limpar datasets e gerar insights visuais utilizando Python.

## 🛠️ O que estou praticando neste projeto:
* **Tratamento de Dados:** Limpeza de planilhas, tradução de colunas e remoção de dados sensíveis.
* **Análise Exploratória:** Uso da biblioteca `Pandas` para entender distribuições e frequências.
* **Visualização:** Criação de gráficos com `Matplotlib` e `Seaborn` para identificar padrões e correlações.
* **Boas Práticas:** Organização de código e versionamento com Git/GitHub.

## 🧪 Tecnologias Utilizadas
* **Python** (Linguagem principal)
* **Pandas** (Manipulação de dados)
* **Matplotlib & Seaborn** (Visualização de dados)
* **NLTK** (Tratamento de similaridades)
